1. PROJECT OVERVIEW (திட்டத்தின் கண்ணோட்டம்)
--------------------------------------------------------------------------------
Thamili AI Agent Platform என்பது பயனர்கள் தங்களின் விருப்பத்திற்கு ஏற்ப அதிநவீன 
செயற்கை நுண்ணறிவு (Artificial Intelligence) முகவர்களை (AI Agents) உருவாக்கவும், 
பயிற்சி அளிக்கவும், குரல் (Voice) மற்றும் உரை (Chat) வழியாக தொடர்பு கொள்ளவும் 
வடிவமைக்கப்பட்ட ஒரு முழுமையான Full-Stack Web Application ஆகும்.

இந்த பிளாட்ஃபார்ம் மூலம் ஹோட்டல் மேலாண்மை, பயணத் திட்டமிடல், மென்பொருள் கோடிங், 
வாடிக்கையாளர் சேவை போன்ற பல்வேறு துறைகளுக்குத் தேவையான AI முகவர்களை எளிதாக 
உருவாக்க முடியும்.


--------------------------------------------------------------------------------
2. USAGE (பயன்பாடு - எதற்காகப் பயன்படுகிறது?)
--------------------------------------------------------------------------------
• Custom AI Agents Creation:
  பயனர்கள் தங்களுக்குத் தேவையான பெயர், பணி (Role), துறை (Domain), அறிவுத்திறன் 
  (System Prompt) மற்றும் குரல் (Voice Persona) அமைத்து புதிய AI ஏஜெண்டுகளை உருவாக்கலாம்.

• Real-time Conversational Voice & Chat Sandbox:
  உருவாக்கப்பட்ட ஏஜெண்டுகளுடன் நேரலையில் உரை (Text Chat) மூலமாகவும் மற்றும் 
  இயற்கையான மனிதக் குரல் (Voice Speech / Speech-to-Text & Text-to-Speech) மூலமாகவும் 
  உரையாடலாம்.

• Real-time Live Tool Integration:
  வானிலை தகவல்கள் (Live Weather Forecast), இணையத் தேடல் (Web Browsing), கோடிங் 
  உதவிகள் போன்ற லைவ் டூல்களை ஏஜெண்டுகளுடன் இணைக்க முடியும்.

• Multi-Domain Ecosystem:
  ஒரே பிளாட்பார்மில் AI Chat, AI Code Generator, AI Image, AI Video, AI Learning 
  போன்ற பல்வகைப்பட்ட கருவிகளைப் பயன்படுத்தலாம்.

• Pre-built Industry Templates:
  Grand Aurora Hotel Concierge, VoyageAI Travel Planner, CodeMaster AI போன்ற 
  முன்கூட்டியே கட்டமைக்கப்பட்ட ரெடிமேட் ஏஜெண்டுகளை உடனடியாகப் பயன்படுத்தலாம்.

3. TARGET AUDIENCE / WHO CAN USE (யாரெல்லாம் பயன்படுத்தலாம்?)
--------------------------------------------------------------------------------
1. வணிக நிறுவனங்கள் மற்றும் தொழிலதிபர்கள் (Business Owners & Enterprises):
   தங்களின் வாடிக்கையாளர்களுக்கு 24/7 தானியங்கி சேவை வழங்க (Customer Support Agents, 
   Hotel Booking Concierge, Sales Assistants).

2. மென்பொருள் உருவாக்குநர்கள் மற்றும் புரோகிராமர்கள் (Software Developers):
   AI அடிப்படையிலான சாட்பாட்கள், வாய்ஸ் அசிஸ்டண்ட்கள் மற்றும் கோடிங் ஏஜெண்டுகளை 
   உருவாக்க மற்றும் ஒருங்கிணைக்க.

3. மாணவர்கள் மற்றும் ஆராய்ச்சியாளர்கள் (Students & AI Learners):
   செயற்கை நுண்ணறிவு, Prompt Engineering, மற்றும் Voice AI தொழில்நுட்பங்களை 
   நேரடியாகக் கற்றுக்கொள்ள.

4. டிராவல் ஏஜென்சிகள் மற்றும் ஹோட்டல்கள் (Hotels & Travel Agencies):
   பயணிகளுக்குத் தேவையான நேரலை வானிலை, தங்குமிடம் மற்றும் பயணத் திட்டங்களை 
   வழங்கும் ஏஜெண்டுகளை அமைக்க.

5. பொதுப் பயனர்கள் (General Users):
   தினசரி பணிகள், தகவல் தேடல், கற்றல் மற்றும் உரையாடல்களுக்கு தனிப்பட்ட 
   ஸ்மார்ட் அசிஸ்டண்டாகப் பயன்படுத்தலாம்.

4. ADVANTAGES & KEY BENEFITS (நன்மைகள் & முக்கிய சிறப்பம்சங்கள்)
--------------------------------------------------------------------------------
• Ultra-Fast Response Time:
  In-Memory Caching முறை மூலம் அடிக்கடி கேட்கப்படும் கேள்விகளுக்கு வெறும் 1 மில்லி 
  செகண்டில் (1ms) பதில் வழங்கும் திறன்.

• Dual-Engine Fallback Architecture:
  Google Gemini API வரம்புகள் அல்லது நெட்வொர்க் தடை ஏற்பட்டாலும், உள்ளமைக்கப்பட்ட 
  High-Speed Domain Fallback Engine மூலம் தடங்கலின்றி பதில் அளிக்கும்.

• Realistic Neural Voice Engine:
  Web Speech API மூலம் குரல் வழியான உள்ளீடு (Voice Input / Mic) மற்றும் இயற்கை 
  ஒலிபெருக்கும் வசதி (Speech Synthesis).

• Pixel-Perfect Modern UI / UX:
  இருண்ட மற்றும் வெளிச்சப் பயன்முறைகள் (Dark / Light Theme), அனிமேஷன்கள், 
  ஒளிரும் Voice Orb, மற்றும் மென்மையான Side Drawer வடிவமைப்பு.

• Zero Configuration Starter:
  நிறுவியவுடனேயே உடனடியாக இயங்கக்கூடிய முன்-வடிவமைக்கப்பட்ட (Pre-configured) 
  ஏஜெண்டுகள் மற்றும் டெம்ப்ளேட்டுகள் உள்ளன.

• Complete Separation of Concerns:
  React 19 Frontend மற்றும் Node.js/Express Backend நேர்த்தியாக பிரிக்கப்பட்டு 
  எளிதில் விரிவாக்கும் வகையில் உருவாக்கப்பட்டுள்ளது.

5. APIS USED (பயன்படுத்தப்பட்டுள்ள API-கள்)
--------------------------------------------------------------------------------
1. Google Gemini Generative Language API (v1beta REST):
   - மாடல்கள்: `gemini-3.6-flash`, `gemini-2.5-flash`, `gemini-2.5-pro`
   - பயன்பாடு: ஏஜெண்டுகளின் அறிவார்ந்த சிந்தனை, உரையாடல் பகுப்பாய்வு மற்றும் பதில்களை உருவாக்குதல்.

2. Open-Meteo Real-Time Weather Forecast API:
   - URL: `https://api.open-meteo.com/v1/forecast`
   - பயன்பாடு: சென்னை மற்றும் பிற நகரங்களின் தற்போதைய வெப்பநிலை, ஈரப்பதம், காற்றின் வேகம் 
     மற்றும் மழை வாய்ப்புகளை உடனுக்குடன் பெறுதல்.

3. Web Speech API (Browser Native APIs):
   - `webkitSpeechRecognition` / `SpeechRecognition`: பயனர் மைக்ரோஃபோன் மூலம் பேசும் 
     குரலை உரையாக மாற்றுதல் (Speech to Text).
   - `window.speechSynthesis`: AI ஏஜெண்டின் பதிலை குரலாக ஒலிக்கச் செய்தல் (Text to Speech).

4. Internal Thamili REST Endpoints (Local Express Server):
   - `GET  /api/health`   : சர்வர் மற்றும் API இணைப்பு நிலையை சோதிக்கும் Endpoint.
   - `GET  /api/weather`  : நேரலை வானிலை தரவுகளைத் தரும் Endpoint.
   - `POST /api/chat`     : பயனர் அனுப்பும் செய்தியை ஆராய்ந்து Gemini AI அல்லது 
                            கேச் செய்யப்பட்ட பதிலை வழங்கும் முதன்மை Endpoint.

6. PROGRAMMING LANGUAGES (பயன்படுத்தப்பட்ட கணினி மொழிகள்)
--------------------------------------------------------------------------------

  Frontend மற்றும் Backend இரண்டிலும் முழுமையாகப் பயன்படுத்தப்படும் நவீன மொழி (Async/Await,

• HTML5:
  வலைப்பக்கத்தின் கட்டமைப்பு, Audio/Video கூறுகள், மெட்டாடேட்டா மற்றும் ரூட் எலிமெண்ட்கள்.

• CSS3 (Modern Vanilla CSS & CSS Variables):
  Flexbox, Grid, Glassmorphism, CSS Custom Variables, அனிமேஷன்கள் மற்றும் ரெஸ்பான்சிவ் 
  லேஅவுட்கள்.

7. TECHNOLOGIES, FRAMEWORKS & LIBRARIES (தொழில்நுட்பங்கள்)
--------------------------------------------------------------------------------
[ Frontend Stack ]
• React 19 (v19.3.0)        : பயனர் இடைமுகத்தை உருவாக்க உதவும் நவீன React பதிப்பு.
• Vite (v8.2.2)             : அதிவேகமான Frontend Build Tool & Development Server.
• React Router DOM (v7.18.3): பக்கங்களுக்கு இடையேயான ரூட்டிங் மற்றும் நேவிகேஷன்.
• Lucide React (v1.33.0)    : உயர்தர நவீன ஐகான்கள் (Icons).
• Canvas Confetti (v1.9.4)  : ஏஜெண்ட் உருவாக்கத்தின் போது தோன்றும் வண்ண கொண்டாட்ட அனிமேஷன்.

[ Backend Stack ]
• Node.js                   : சர்வர் பக்க ஜாவாஸ்கிரிப்ட் ரன்டைம் சூழல்.
• Express.js (v4.21.2)      : இலகுவான மற்றும் வேகமான HTTP Web REST API Framework.
• CORS (v2.8.5)             : Frontend மற்றும் Backend இடையேயான Cross-Origin Resource Sharing அனுமதி.
• Dotenv (v16.4.7)          : பாதுகாப்பு சார்ந்த ரகசிய சாவிகள் (API Keys) மற்றும் சூழல் மாறிகளை (.env) நிர்வகிக்க.
• In-Memory Cache Engine    : Map அடிப்படையிலான Time-To-Live (TTL) அதிவேக கேச்சிங் அமைப்பு.

[ Tooling & Developer Utilities ]
• Concurrently (v10.0.5)    : ஒரே கமாண்டில் Frontend மற்றும் Backend இரண்டையும் ஒரே நேரத்தில் இயக்க.
• Oxlint (v1.79.0)          : அதிவேகமான Rust-அடிப்படையிலான JavaScript/React Linter.

8. OPTIONS & FEATURES (அம்சங்கள் மற்றும் விருப்பங்கள்)
--------------------------------------------------------------------------------
1. Agent Hub:
   - அனைத்து ஏஜெண்டுகளையும் ஒரே பார்வையில் காணும் பிரதான டாஷ்போர்டு.
   - ஏஜெண்டுகளை தேடுதல் (Search), ஃபில்டர் செய்தல் மற்றும் புதிய ஏஜெண்டுகளைத் தேர்ந்தெடுக்கும் வசதி.

2. Create Agent Studio:
   - ஏஜெண்ட் பெயர், பதவி (Role), பிரிவு (Domain) நிர்ணயித்தல்.
   - தனிப்பயன் System Instructions / Prompts எழுதுதல்.
   - அவதார் (Robot / Assistant Avatar) தேர்வு செய்தல்.
   - நேரலை டூல்கள் ஆன்/ஆஃப் செய்தல் (Live Weather, Web Search, Code Helper).
   - குரல் அமைப்புகள் (Voice Persona, Pitch, Speed, Accent).

3. Choose Agent Screen:
   - ஏற்கனவே உள்ள சிறந்த முன்-வடிவமைக்கப்பட்ட ஏஜெண்டுகளில் இருந்து ஒருவரை தேர்வு செய்தல்.

4. Live Interactive Agent Side-Preview Drawer:
   - எந்த பக்கத்தில் இருந்தாலும் திரையின் வலது பக்கத்தில் ஏஜெண்டுடன் உடனுக்குடன் 
     பேசிப் பார்க்கும் வசதி.

5. Voice Sandbox & Pulsing Voice Orb:
   - AI பேசும்போதும் கேட்கும்போதும் ஒளிரும் அனிமேஷன் கொண்ட Voice Orb.
   - ரோபோட் உரையாடல் பலூன் (Robot Speech Dialog).

6. Multi-Tool Ecosystem Views:
   - AI Code Studio: கோடிங் தவறுகளைக் கண்டறிந்து திருத்தும் பகுதி.
   - AI Image Generator UI: படங்களை உருவாக்கும் இடைமுகம்.
   - AI Video Generator UI: வீடியோ உருவாக்கும் இடைமுகம்.
   - AI Learn: செயற்கை நுண்ணறிவு பற்றிய கல்வி மற்றும் உதவிப் பகுதி.
   - History View: முந்தைய உரையாடல்களைப் பார்க்கும் வசதி.

  அட்சரேகை/தீர்க்கரேகை (13.0827, 80.2707) ஆகியவற்றை வழங்கும் கட்டமைப்பு கோப்பு.

• backend/routes/apiRoutes.js:
  `/api/health`, `/api/weather`, `/api/chat` ஆகிய URL பாதைகளை உரிய கன்ட்ரோலர்களுடன் 
  இணைக்கும் ரவுட்டிங் கோப்பு.

• backend/controllers/chatController.js:
  சாட் கோரிக்கைகளைப் பெற்று, அது வானிலை சார்ந்த கேள்வியா என்பதை ஆராய்ந்து, தேவையானால் 
  வானிலை தகவல்களைச் சேர்த்து, ஜெமினி AI-க்கு அனுப்பி பதிலை அனுப்பும் கன்ட்ரோலர்.

• backend/controllers/weatherController.js:
  வானிலை கோரிக்கைகளைப் பெற்று, தற்போதைய வெப்பநிலை மற்றும் காலநிலையை அனுப்பும் கன்ட்ரோலர்.

• backend/services/geminiService.js:
  Google Gemini AI உடன் பாதுகாப்பாக உரையாடி விரைவான பதில்களைப் பெறும் முதன்மை சேவை. 
  கூகுள் API வரம்புகள் முடிந்தாலும் கூட உள்ளூர் Fallback Engine வழியாக உடனடியாக ஆங்கிலத்தில் 
  பதில் தயாரிக்கும் திறன் கொண்டது.

• backend/services/weatherService.js:
  Open-Meteo வானிலை சர்வரில் இருந்து தகவல்களைப் பெற்று, WMO வானிலை குறியீடுகளை எளிய 
  சூரியன், மழை எமோஜிகளாக மாற்றி, 15 நிமிடங்களுக்கு நினைவகத்தில் சேமித்து (Cache) 
  வழங்கும் சேவை.

• backend/services/cacheService.js:
  உயர்வேக இன்-மெமரி (In-Memory Map) கேச்சிங் சர்வீஸ். ஒரே மாதிரியான கேள்விகளுக்கு 
  மீண்டும் மீண்டும் API-ஐ அழைக்காமல் வெறும் 1ms-ல் பதில் கொடுக்க உதவுகிறது.

================================================================================
10. HOW TO RUN THE PROJECT (ப்ராஜெக்ட்டை எவ்வாறு இயக்குவது?)
================================================================================

1. தேவைகள் (Prerequisites):
   - கணினியில் Node.js (v18 அல்லது அதற்கு மேல்) நிறுவப்பட்டிருக்க வேண்டும்.

2. டிபென்டென்சிகளை நிறுவுதல் (Install Dependencies):
   டெர்மினலில் பின்வரும் கட்டளையை இயக்கவும்:
   npm install

3. ஒரே நேரத்தில் Frontend & Backend இரண்டையும் இயக்குதல் (Run Dev Server):
   npm run dev

   - Frontend இயங்கும் தளம் : http://localhost:5173
   - Backend API இயங்கும் தளம்: http://localhost:5000

4. தனித்தனியாக இயக்குவதற்கான வழிகள் (Optional):
   - Frontend மட்டும் இயக்க : npm run dev:client
   - Backend மட்டும் இயக்க  : npm run server
